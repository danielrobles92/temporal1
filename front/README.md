# Perreque - Plataforma de Adopción de Mascotas

Plataforma web para adopción de mascotas y búsqueda de mascotas perdidas.

## Características

- 🐕 Adopción de mascotas
- 🔍 Búsqueda de mascotas perdidas
- 📝 Publicación de anuncios
- 👤 Gestión de perfiles de usuarios
- 🗺️ Búsqueda por ubicación

## Tecnologías

- React 18
- React Router DOM
- JavaScript (ES6+)

## Instalación

```bash
npm install
```

## Ejecutar en desarrollo

```bash
npm start
```

La aplicación se abrirá en [http://localhost:3000](http://localhost:3000)

## Construir para producción

```bash
npm run build
```
